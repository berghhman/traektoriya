# Сайт «Траектория»

Статический сайт строительной компании. Восемь страниц плюс страница заявки,
без сборщиков и зависимостей: HTML, один файл стилей, один файл скриптов.

## Структура

```
index.html                 Главная
villageprojects.html       Загородное строительство: проекты домов
villagerealization.html    Загородное строительство: как это выглядит
projects.html              Жилые комплексы: входные группы
otdelkajk.html             Жилые комплексы: отделка квартир
partners.html              Партнёры
about.html                 О компании
contacts.html              Контакты
zayavka.html               Форма заявки

assets/site.css            Оформление: токены, сетка, компоненты
assets/site.js             Скрипты: загрузка, меню, галереи, лента, форма
assets/MagistralC-Bold.woff  Шрифт заголовков
assets/img/                Фотографии по разделам

build.py                   Сборщик страниц
```

## Правка контента

Тексты, списки объектов, галереи и описания проектов собраны в build.py.
После правки:

```
python3 build.py
```

Команда пересобирает все девять страниц. Вручную HTML не редактируется:
изменения затрутся при следующей сборке.

## Что требует заполнения

- build.py, список TR: рабочие названия проектов вместо кодов ТР 01-04
- build.py, переменная SITE_URL: адрес сайта для тегов Open Graph
- index.html, массив PHRASES: фразы бегущей строки на главной
- assets/site.js, переменная FORM_ENDPOINT: обработчик формы заявки.
  Пока пуста, заявка уходит письмом через почтовую программу
- assets/site.js, переменная MAIL_TO: адрес для писем с заявками
- zayavka.html, ссылка id="f-policy": политика обработки персональных данных
- partners.html: описания партнёрств, кроме SetlGroup

## Публикация

Внешних зависимостей нет, кроме шрифта Golos Text с Google Fonts.
Папка заливается на любой статический хостинг как есть.

Возраст компании считается от 2013 года (YEAR_FOUNDED в build.py)
и обновляется автоматически.
